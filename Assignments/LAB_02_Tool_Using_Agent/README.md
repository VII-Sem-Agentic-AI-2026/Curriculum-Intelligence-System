# Lab 2 — Tool-Using Agent

**Concept (book spec):** Agents must call tools to act rather than answering from their own memory.

## 1. Concept applied
Three real, deterministic checks: credit-total consistency (176 = sum of 8 declared semesters), course-code-year staleness, and industry skill coverage (keyword match against real syllabus topics). Every number the pipeline reports is computed here, never generated by the LLM.

**app/tools.py** (excerpt):
```python
def compute_credit_total_check(curriculum: dict) -> ToolResult:
    declared = curriculum["declared_semester_credits"]
    computed_total = round(sum(declared.values()), 2)
    stated_total = curriculum["total_program_credits"]
    errors = [] if computed_total == stated_total else [
        f"Semester totals sum to {computed_total}, document states {stated_total}."]
    return ToolResult(not errors, {"computed_total": computed_total, "stated_total": stated_total,
                                     "per_semester": declared}, errors)
```
